# 🚨 AI Incident Investigation Assistant

An AI-powered Streamlit application that analyzes incident descriptions, predicts root causes, evaluates risk, and generates investigation reports.

## Features
- NLP-based Root Cause Prediction
- Risk Assessment (5x5 Matrix)
- CAPA Recommendations
- Compliance Detection
- Analytics Dashboard
- Auto Report Generation

## Run Locally
pip install -r requirements.txt  
streamlit run app.py
